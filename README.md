# addon-updates

Update-Kanal für die selbstverteilte Firefox-Version der Erweiterung.
Enthält ausschliesslich `updates.json` und die von Mozilla signierten
XPI-Dateien.

**Dieses Repository wird nie umbenannt.** Die Adresse
`https://cossabuilds.github.io/addon-updates/updates.json` steckt fest in
jeder ausgelieferten XPI-Datei. Wird sie unerreichbar, verlieren alle
installierten Kopien still ihre Updates — reparieren liesse sich das nicht
per Update, weil das Update selbst der kaputte Weg wäre.

Der Name enthält deshalb bewusst keinen Produktnamen.
